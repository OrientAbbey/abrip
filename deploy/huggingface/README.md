# ABRIP

Observation du routage inter-domaines africain à partir de données publiques :
visibilité des préfixes, dépendance au transit, et détection d'anomalies
accompagnées de leurs preuves.

Ce Space embarque un jeu de démonstration avec des anomalies plantées, ce qui
permet de parcourir l'interface sans télécharger d'archives.

Code source et documentation : voir le dépôt du projet.
